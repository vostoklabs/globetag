# Map data

Natural Earth public-domain map data, downloaded from the official maintainer's natural-earth-vector repository with scripts/map-data.mjs.

- Countries: ne_110m_admin_0_countries
- Lakes: ne_110m_lakes
- City search and labels: ne_10m_populated_places_simple

https://www.naturalearthdata.com/about/terms-of-use/
https://github.com/nvkelso/natural-earth-vector

Coordinates and names are simplified. Not all settlements are represented. Geographic boundaries reflect this dataset, not a statement by this project.
